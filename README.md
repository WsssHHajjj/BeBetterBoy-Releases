# BeBetterBoy Desktop

Windows 本地画面遮挡工具，支持实时桌面识别，以及图片、动画和视频处理。识别在本机完成，画面无需上传。

## 主要功能

- **实时遮挡**：识别人物剪影、身体皮肤、面部皮肤及指定部位，可选择显示器和应用范围。
- **多种样式**：像素、模糊、纯色、贴纸、描边及多种特效，支持调整大小、透明度、字幕和文字墙。
- **文件处理**：批量处理图片、动画与视频，视频可保留音轨。
- **日常使用**：托盘运行、快捷键、临时查看、配置预设与更新检查。
- **锁定功能**：可选密码或定时锁定；启用前请阅读客户端提示，升级或卸载前需先解锁。

## 下载与安装

前往 [Releases 下载最新版](https://github.com/WsssHHajjj/BeBetterBoy-Releases/releases/latest)，运行 **BeBetterBoy-Setup-x64.exe**，按提示完成安装及管理员授权。

需要 **Windows 11 x64**，建议更新系统和显卡驱动。安装包包含运行环境与模型，无需安装 Python。

## 简单用法

1. 在“检测目标”中勾选需要遮挡的目标。
2. 在“遮挡样式”中选择效果并调整参数。
3. 打开右上角总开关，开始实时遮挡；关闭开关即可暂停。
4. 处理本地文件时，进入“媒体处理”，添加文件并开始处理。

默认快捷键：**Ctrl + Alt + F8** 暂停／恢复，**Ctrl + Alt + F9** 临时查看。可在“界面与偏好”中修改。

关闭主窗口默认进入托盘，正在运行的遮挡会继续；彻底退出请使用托盘菜单中的“退出”。

## 更新

客户端默认在启动时检查更新，也可在“帮助”页手动检查。发现新版后下载并确认安装，升级会保留用户设置。旧版本若没有更新入口，请手动下载安装最新版。

识别可能出现漏检或误检，可按使用场景调整目标与阈值。第三方模型和组件的许可证见客户端“帮助 → 模型与许可证”。
